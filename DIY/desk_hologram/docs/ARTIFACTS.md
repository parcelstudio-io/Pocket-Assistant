## Adding a page

1. Put the content in the generator (or a new one in `pages/gen/`), with inline SVG that shows the mechanism.
2. Save the HTML into `pages/` before publishing; regenerate the PDF with `--pdf`.
3. Publish, then add a row above with the source file and the date.
