# Prompts

Prompts I reuse across DIY projects. Copy one, fill in the `<placeholders>`, and paste it into a new session.

## Initialize a project directory

Run from a new, empty project folder (e.g. `DIY/<project_name>/`).

```text
Create the hardware and software setup. Verify all the components, design, and
assembly required to create the <thing> in <reference URL>.

I want you to analyze the spec and see how we can build this with actual
product links that I can buy.
```

Example:

```text
Create the hardware and software setup. Verify all the components, design, and
assembly required to create the drone in https://www.youtube.com/watch?v=Sa6EslOHsI0

I want you to analyze the spec and see how we can build this with actual
product links that I can buy.
```
