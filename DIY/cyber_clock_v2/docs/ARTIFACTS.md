# Published pages (Claude artifacts)

Build guides for Cyber Dawn are published as illustrated web pages alongside the
Markdown here. Each page is built from a repository file, which stays the
authority; the page adds diagrams of the mechanisms. If a page and the
repository disagree, the repository wins.

The HTML source for every page lives in [`pages/`](pages/) so it can be edited
and republished later. The links are private to the builder's Claude account
until shared from each page's Share menu.

## Related, in the other project

The electronics fundamentals these guides assume are taught in
`pocket_ai_assistant/edu/` — see that project's `edu/ARTIFACTS.md`. Two pages
there are directly load-bearing for this build:

- **Resistors and Rules** — pull-ups and pull-downs, which is why the real-time clock's
  interrupt needs its 10 kΩ and why the button reads active-low.
- **The Pin Switchboard** — what a GPIO is, RTC-capable pins, push-pull versus
  open-drain, and the four layers of code that claim a pin.

In this project, two documents without pages carry the Rev B decisions of
2026-10-31: [`SCREEN_RESEARCH.md`](SCREEN_RESEARCH.md) (why the owned OLED
stays) and [`COMPACT_DESIGN.md`](COMPACT_DESIGN.md) (the 82 × 52 × 68 mm body).

## Adding a page

1. Build the page from the repository file with inline SVG diagrams that show
   mechanisms, not decoration.
2. **Save the page's HTML into `pages/` before publishing.** Anything left in a
   scratchpad directory is lost when the session ends.
3. Publish it, then add a row above with the source file and the date.
