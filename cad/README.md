# CAD status and regeneration

`fitcheck.py` is the editable source for the Rev A placement study. It uses
manufacturer envelopes for the named holder, OLED, regulator, switch,
amplifier, speaker box, and capacitor. The generic ESP32-C3 SuperMini and
INMP441 breakout still use provisional marketplace dimensions; measure the
received boards and update the script before fabrication.

The existing `pager_rev_a.FCStd`, `pager_rev_a.step`, and
`FITCHECK_REPORT.md` were generated by Claude before the final audit. They
used the wrong MPD BH123A dimensions, a discontinued capacitor, and an
incomplete antenna keepout, so they are preserved for provenance but are not
fit evidence. Regenerate them after installing FreeCAD:

```bash
freecadcmd cad/fitcheck.py
```

Accept a new report only when every rule passes with measured part envelopes,
wire-bend room, insulation, fasteners, cell insertion/removal, and actual
connector plugs represented. A 1:1 cardstock/caliper dry fit remains required.
